# Microsoft-Purview

Microsoft-Purview is a collection of tools and resources for integrating Microsoft Purview with various data sources and platforms. This repository contains notebooks, scripts, and documentation to facilitate the extraction, transformation, and loading (ETL) of metadata and lineage information into Microsoft Purview.

## Fabric to Purview Lineage Extractor

This tool extracts lineage information from Microsoft Fabric and loads it into Microsoft Purview, enabling comprehensive data governance and lineage tracking across your data estate.
